Installer l’extension Uber Fleet

L’extension lit les chauffeurs affichés sur votre carte Uber Fleet et les transmet à Ludy sur cet ordinateur. Gardez Ludy ouvert pendant son utilisation.

Chrome ou Microsoft Edge

Télécharger l’extension Chrome / Edge
  1. Enregistrez le ZIP, puis extrayez-le dans un dossier que vous conserverez.
  2. Dans Chrome, saisissez chrome://extensions dans la barre d’adresse. Dans Edge, utilisez edge://extensions.
  3. Activez le Mode développeur, puis cliquez sur Charger l’extension non empaquetée.
  4. Sélectionnez le dossier extrait contenant le fichier manifest.json.

Associer votre écran Uber

  1. Dans Ludy, connectez-vous avec le compte administrateur du poste de collecte et activez Participer à la collecte. Attendez Collecte active sur ce poste.
  2. Dans Connecteurs → Uber Fleet, cliquez sur Associer mon écran Uber et copiez le code.
  3. Ouvrez la Live Map Uber Fleet dans Chrome ou Edge. Dans l’extension Ludy, collez le code, puis cliquez sur Associer et Démarrer.

Gardez la carte ouverte et la liste des chauffeurs sans filtre restrictif. L’option « Reprendre automatiquement » facilite la reprise ; une session Uber expirée demande une nouvelle connexion.

Rapports Uber

Pour les rapports automatiques, utilisez Connecter Uber dans Ludy puis renseignez la flotte dans Rapports automatiques. Le navigateur dédié s’ouvre sur ce poste ; connectez-vous à Uber et gardez-le ouvert. La Live Map et les rapports utilisent des sessions distinctes.

Si vous utilisez ce navigateur pour les rapports, arrêtez la collecte des rapports dans l’extension et conservez sa lecture de la Live Map.
